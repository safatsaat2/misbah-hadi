# Misbah Hadi — Portfolio

Static portfolio site for Misbah Hadi, Creative Artist & Video Editor.

## Local preview

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

### Option 1: Vercel CLI

```bash
npm i -g vercel
vercel
```

Follow the prompts. For production:

```bash
vercel --prod
```

### Option 2: GitHub + Vercel Dashboard

1. Push this folder to a GitHub repository.
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import the repository.
4. Leave **Framework Preset** as **Other** (no build step required).
5. Click **Deploy**.

Vercel will serve `index.html` automatically.

## Assets

Add a `personal.jpg` file to the project root for the hero and about photos. If it is missing, the site falls back to placeholder images.
